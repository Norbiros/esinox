# ESinOxc

🐂 Run ESLint plugins inside oxlint.

**esinoxc** (/ɛs ɪn ɒks/) stands for [**ES**Lint](https://eslint.org) **in** [**Oxc**](https://oxc.rs) (Lint).

## Development

- Install dependencies:

```bash
vp install
```

- Run the unit tests:

```bash
vp test
```

- Build the library:

```bash
vp pack
```
