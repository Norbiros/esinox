# ESinOxc

🐂 Run ESLint plugins inside oxlint.

**esinoxc** (/iː-ɛs-ɪn-oʊ-ɛks-siː/) stands for [**ES**Lint](https://eslint.org) **in** [**Oxc**](https://oxc.rs).

## Development

- Install dependencies:

```bash
vp install
```

- Run the unit tests:

```bash
vp test
```

- Build the library:

```bash
vp pack
```
